# Запуск Mini App в Telegram

Статус: в работе · 23 ноября 2026. Worker опубликован, вебхук и Main Mini App подключены. Проверены партии в обеих играх через публичный API. Открытие приглашения со второго аккаунта Telegram ещё не проверено.

Связано: [запуск проекта](../../README.md), [сценарий партии](../specs/партия-по-ссылке.md).

## Задача 1: проверить локальный сервер

Файлы: `src/server.js`, `test/server.test.js`.

- Запусти `npm test`. Проверка «Два игрока получают одну позицию через API в обеих играх» должна пройти.
- Проверь, что Telegram через `getMe` возвращает `DoskaPlayBot`. Не выводи токен.
- Коммит не нужен: задача проверяет существующий код.

## Задача 2: поднять приложение по HTTPS

Файлы: `.env` (вне Git), `README.md`.

- Выбери хостинг с Node.js 24, публичным HTTPS и постоянным диском для SQLite. Передай настройки через переменные окружения хостинга. Запусти один экземпляр через `npm start`.
- Укажи публичный адрес в `APP_URL`. Проверь командой `curl.exe -fsS АДРЕС`, что сервер отдаёт страницу с заголовком «Доска».
- Коммит не нужен, если код и инструкция запуска подходят хостингу.

## Задача 3: привязать адрес и открыть партию

Файлы: `README.md` (результат проверки).

- Укажи тот же HTTPS адрес в Main Mini App у BotFather.
- Отправь `/start` боту. Нажми «Играть» и создай комнату. Проверь, что приглашение содержит `startapp` и открывает ту же комнату со второго аккаунта.
- Сделай по ходу в каждой игре. Соперник должен увидеть обновление после очередного запроса, который отправляется раз в 2 секунды. Открой приглашение ещё раз и сравни позицию.
- Коммит «Записать результат проверки Mini App в Telegram».
