# Партии по ссылке: план реализации

Статус: в работе · 23 ноября 2026. Сценарий согласован, код и проверка в Telegram впереди.

Связано: [спецификация](../specs/партия-по-ссылке.md).

## Устройство проекта

Один процесс Node.js 24 обслуживает бота, API и статический Mini App. SQLite хранит комнаты и историю. Сервер отдаёт позицию и допустимые ходы. После каждого запроса на ход он возвращает актуальное состояние партии.

## Задача 1: правила игры

Файлы: `src/games.js`, `src/draughts.js`, `test/games.test.js`.

- Подключи `chess.js` для шахмат и реализуй русские шашки. Верни позицию, допустимые ходы, очередь и результат.
- Добавь проверки «Начальная шахматная позиция» (20 ходов), «Превращение пешки» (4 варианта), «Обязательное взятие» (обычные ходы исключены) и «Серия взятий» (очередь меняется после последнего взятия).
- Запусти `node --test test/games.test.js`. Все проверки должны пройти.
- Коммит «Добавить правила шахмат и русских шашек».

## Задача 2: комнаты и сохранение партии

Файлы: `src/rooms.js`, `src/telegram.js`, `src/server.js`, `test/rooms.test.js`.

- Проверь подпись данных запуска Telegram и срок действия 24 часа. Бери идентификатор игрока из подписанных данных.
- Добавь создание комнаты, вход по ссылке, чтение состояния и ход. Назначь создателя белыми. Записывай ход только для текущей версии комнаты и игрока, за которым очередь.
- Добавь проверки «Третий игрок» (403), «Ход вне очереди» (403), «Устаревшая версия» (409), «Повторный вход» (та же сторона и позиция) и «Перезапуск сервера» (партия сохранена).
- Запусти `node --test test/rooms.test.js`. Все проверки должны пройти.
- Коммит «Добавить комнаты и сохранение партий».

## Задача 3: бот и доска

Файлы: `public/index.html`, `public/app.js`, `public/style.css`, `src/bot.js`, `README.md`.

- Добавь кнопку «Играть» в боте. Покажи выбор игры, ссылку приглашения, доску и результат. Подсвечивай допустимые клетки. Запрашивай состояние раз в 2 секунды на экране партии.
- Опиши запуск с токеном бота и адресом Mini App по HTTPS.
- Запусти `npm test`. После настройки бота проверь с двух аккаунтов: белые делают ход, чёрные видят новую позицию не позднее следующего запроса, повторное открытие возвращает к той же партии. Повтори для обеих игр.
- Коммит «Подключить бота и игровую доску».
